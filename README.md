# Задание 1

## Задача 1

### Текст задачи
Разработать класс с тремя целочисленными полями. Создать конструктор копирования. 
Разработать метод, вычисляющий максимальное из полей. Перегрузить метод ToString() для 
формирования строки из полей класса. Реализовать дочерний класс (его содержание предложить 
самостоятельно и описать в решении: какой содержательный смысл имеют поля; реализовать 
конструкторы; предложить и реализовать 2-3 метода). Протестировать все конструкторы и 
другие методы базового и дочернего классов. 

### Алгоритм решения
У нас есть класс Box (коробка) с тремя целочисленными полями _length, _width, _height, которые соответствуют длине, ширине и высоте посылки. Также в классе есть копирующий конструктор, пустой и с тремя значениями. Также есть метод вычисления большего значения среди полей, свойства полей и перегрузка ToString(). В дочерний класс Package (посылка) были добавлены такие поля как _weight (вес) и _frigale (хрупкость). Также дочерний класс имеет 3 конструктора (пустой, копирования и со значениями), методы для выводах о транспортировке и упаковке посылки, и также перегрузка метода ToString().

# Задание 2-3

## Задача 1

### Текст задачи
Point double x, double y 
(координаты точки) 
Вычислить расстояние от одной точки до 
другой. 
Результат должен быть типа double. 

Point Унарные операции: 
++ увеличить координаты xна 1, -- уменьшение координаты х на 1. 
Операции приведения типа: 
int (явная) – результатом является целая часть координаты х; 
double (неявная) – результатом является координата y. 
Бинарные операции: 
+ Point p – вычисляется расстояние до точки p. Результатом должно быть 
вещественное число.  
+ целое число (лево- и правосторонние операции). Увеличивается 
координата х, результатом является объект типа Point. 

### Алгоритм решения

Реализован класс Point с двумя полями означающими координаты точки (поля типа double), 3 конструкторами (пустым, копирующим и с двумя аргументами). Метод Length вычисляет расстояние от одной точки до другой. Есть дополнительный класс Checking для проверки введенным пользователем значений. Также для третьего задания реализованы операции привидения (типа int(явная) - целое число x, double(неявная) - вещественный у), бинарные операции (+ Point p, точка + целое число, целое число + точка), перегрузка ToString()
